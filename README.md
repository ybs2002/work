# 🍚 우리집 식단 관리

가족의 일주일 식단을 짜고, 장보기 목록을 자동으로 만들어 주는 웹 앱이에요.

## 실행 방법
`index.html` 파일을 더블클릭해서 브라우저로 열면 끝! (설치 필요 없음)

## 📱 폰 홈 화면에 앱처럼 추가하기
1. 이 앱을 인터넷 주소로 올려요 (GitHub Pages: 저장소 **Settings → Pages** 에서 `main` 브랜치, `/ (root)` 선택)
2. 폰 브라우저로 `https://ybs2002.github.io/work/` 를 열어요
3. 홈 화면에 추가해요
   - 아이폰(Safari): 공유 버튼 → **홈 화면에 추가**
   - 안드로이드(Chrome): 오른쪽 위 ⋮ → **홈 화면에 추가** (또는 **앱 설치**)

한 번 열어 두면 인터넷이 없어도 열려요.

## 기능
| 탭 | 하는 일 |
|---|---|
| 📅 주간 식단 | 요일 카드마다 아침/점심/저녁 메뉴 고르기. 🎲 버튼으로 메뉴 추천, 🪄 버튼으로 빈칸 한 번에 채우기. 못 먹는 재료가 있으면 ⚠️ 경고 |
| 🍳 메뉴 | 메뉴 이름과 재료 등록/삭제 |
| 👨‍👩‍👧 가족 | 가족 이름과 못 먹는 재료(알레르기 등) 등록/삭제 |
| 🛒 장보기 | 식단에 들어간 재료를 자동으로 모아서 체크리스트로 보여줌. 재료마다 몇 번 쓰이는지 표시, 산 재료는 아래로 |

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 화면의 뼈대 (무엇이 어디에 있는지) |
| `style.css` | 꾸미기 (색깔, 크기, 배치) |
| `app.js` | 동작 (버튼 누르면 무슨 일이 일어나는지, 저장) |
| `manifest.json` | 앱 정보표 (이름, 아이콘, 색깔) |
| `sw.js` | 오프라인 도우미 (인터넷 없어도 열리게 파일을 저장해 둠) |
| `icons/` | 홈 화면 아이콘 그림 |

데이터는 브라우저(localStorage)에 저장돼서 창을 닫아도 남아 있어요.
